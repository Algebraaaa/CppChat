# QQNT expression resources

Source: https://github.com/koishijs/QFace

Revision: `c96fa14ff894147ac0442dda0fce6a4523e5fcbd`

Names and search aliases come from the pinned QQNT index. Hidden entries, entries without static images, and duplicate names are omitted.
