# 界面代码分工

`dialogs` 下的页面和弹窗使用同名 `.h`、`.cpp`、`.ui` 文件。
固定控件和布局优先写在 `.ui` 中，便于用 Qt Designer 查看和调整。

- `.ui`：控件层级、布局、尺寸、间距、静态文字、图标以及默认状态。
- `.cpp`：信号连接、输入校验、业务请求、数据更新、弹窗定位和运行时状态。
- QSS：颜色、边框、字体、圆角，以及悬停、按下、选中和焦点的样式。

不在构造函数里重复创建 `.ui` 已经定义的固定控件，也不额外保存同一个控件指针，
直接通过 `ui->控件名` 访问。现有模块目录中的 `.cpp/.h/.ui` 由客户端 CMake 自动收录；
新增模块目录时更新 `CMakeLists.txt`，界面文件由 AUTOUIC 处理。

快捷操作菜单使用 `quickactionmenu.ui`；消息右键菜单使用 `messagemenu.ui`。
聊天记录的分类、结果列表和分页按钮在 `chathistorydialog.ui`；
聊天状态提示在 `chatpage.ui`；会话列表未读红点在 `chatuserwid.ui`。

随数据数量变化的消息条目、时间分隔符、图片和气泡由 C++ 动态创建。
这些内容的绘制和自适应尺寸属于自定义控件的职责；固定页面骨架仍由 `.ui` 定义。
