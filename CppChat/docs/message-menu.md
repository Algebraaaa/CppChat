# 消息体右键菜单

在聊天页的文字、表情或图片消息上点击右键，打开微信式浅色圆角菜单。菜单项顺序为：
复制、放大阅读、翻译、搜一搜、转发、收藏、多选、提醒、引用、删除。
分隔线、图标列和行高由 `dialogs/messagemenu.ui` 定义，配色在
`style/pages/dialogs.qss` 的 `QWidget#MessageMenu` 规则中设置。

复制已接入：文字消息复制原始正文，表情保留文字标记；图片消息复制已下载的原图。
图片尚未加载成功时禁用复制。其他上述操作仅显示“功能暂未实现”的状态提示，
包括删除；不会修改消息记录或向服务端发送操作请求。

发送失败且未确认的消息额外显示“重试发送”。它仍使用原有重试逻辑、原消息编号，
仅在连接有效并且服务端支持消息去重时启用。右键发送状态文字也可以打开此菜单。

事件路径：TextBubble 的 QTextEdit 或 BubbleFrame 接收右键，统一发出全局坐标信号；
ChatItemBase 转发给 ChatPage，ChatPage 创建 MessageMenu 并绑定当前消息。
文字编辑器不再弹出原生右键菜单；图片的左键预览和下载重试保持原有实现。

菜单使用 Qt::Popup，点击外部或按 Esc 收起，关闭后延迟释放。
位置限制在当前屏幕可用范围内。鼠标点击不会留下焦点背景；Tab、上下方向键以及
Enter 支持键盘操作，焦点用细边框显示。

新增图标复用 [Lucide](https://github.com/lucide-icons/lucide) 的固定版本和项目已有许可证，
具体资源映射见 `Resources/icons/README.md`。
