# 消息菜单与本机收藏

更新日期：2026-10-19，客户端版本 0.1.15。聊天消息右键菜单支持复制、放大阅读、
聊天记录查找、转发、收藏、多选、文字引用及仅本机删除；翻译仍为未开放入口，
消息提醒在下述本地开发版中补齐。
图片左键沿用原有查看器，未确认消息保留原 UUID 的重试发送入口。

2026-10-19 本地开发版新增消息提醒：右键已确认消息设置未来时间，收藏页“提醒事项”管理，
客户端登录运行时检查，退出不运行后台服务；到期状态保留到完成/取消。独立笔记也已接入
收藏页和聊天加号菜单，保存、编辑、另存与发送均使用真实本机存储和既有发送器。
原提醒占位及转发/收藏/多选的过时工具提示已经更新。详见 [界面功能](ui-features.md)。

放大阅读使用只读纯文本编辑器，支持调节字号和复制全文，不解析 HTML 或加载网页。
引用将发送者及最多 1024 个 UTF-16 单元、8 行的摘要插入草稿，保留原文字和图片，
可一次撤销；发送仍是兼容旧端的普通文字，不包含结构化跳转关系。
聊天记录查找打开现有本地历史窗口，支持分页、关键词、类型及日期查询。

已确认消息可收藏或转发。收藏先完整读取媒体，再把独立快照保存到当前服务器及账号的
加密 SQLite（v3 起）；文字、发送者、时间、图片字节及 SHA256 均在本机保存。每页 50 项，
支持字面关键词搜索、近七天、链接、图片、文字分类、查看、取消及重新发送。
列表不批量读取图片 BLOB，打开时读取所选内容并校验。取消收藏不删除原聊天，
清空聊天或删除原消息也不会破坏收藏。没有云端收藏同步，独立笔记未开放。

转发明确选择好友或群聊目标，保留源会话及目标会话已有草稿，每条生成新 UUID。
图片复用原有传输，按新收件人重新协商资源并上传，不把旧下载 ID 当成新目标的授权。
服务器协商 `group_images` 后也可发往群聊，重新按目标群授权上传。
创建私聊只接收自身目标匹配的回包；
取消、断线及切换账号撤销尚未提交的选择。上传或确认失败的消息保留在现有本机
待确认记录中，按原重试规则处理。

多选最多 50 条已确认消息，可批量收藏、逐条转发及仅本机删除；切换会话、隐藏页面、
切换账号或按 Esc 结束选择。一次准备媒体最多 64 MiB，图片沿用 20 MiB 上限。
批量删除默认取消，确认后在同一事务写隐藏标记及删除本机记录；失败全部回滚，
提交后刷新。历史补拉及重复通知不会恢复隐藏消息，不删除服务器或其他设备的记录。

`MessageActions` 处理菜单意图，`MessageSnapshotService` 复用授权下载及账号附件缓存，
`MessageForwarder` 处理目标选择和私聊请求，`MessageSender` 持久化并传输新消息；
`ChatStore` 在同一工作线程执行绑定参数、事务和幂等升级，页面不直接执行 SQL。
不新增第三方依赖、媒体协议或云端表。图标沿用项目固定的
[Lucide](https://github.com/lucide-icons/lucide)，许可见 `Resources/icons/README.md`。

本轮参考 [SQLite UPSERT](https://www.sqlite.org/lang_upsert.html)、
[事务语义](https://www.sqlite.org/lang_transaction.html) 与
[Qt QSqlQuery](https://doc.qt.io/qt-6/qsqlquery.html)、
[QObject 生命周期](https://doc.qt.io/qt-6/qobject.html)、
[QPointer](https://doc.qt.io/qt-6/qpointer.html) 及
[Qt Item Views 示例](https://doc.qt.io/qt-6.12/examples-itemviews.html)。
复用已锁定的 Qt/SQLite 能力，不复制第三方业务源码，不引入额外许可或编译器要求。

`client.favorites`、`client.messages`、`client.features` 覆盖独立媒体、账号隔离、重开、
搜索分页、校验失败、事务回滚、实际菜单及选择、目标和 UUID、草稿保留、新目标上传及
取消后的晚到回包。自动截图和回环夹具不代替真人、多屏及弱网验收。
