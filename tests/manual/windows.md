# Windows 桌面人工验收

自动化通过不替代本清单。只能使用隔离测试账号和配置；生产账号不在范围内。记录构建、Qt Kit、编译器、Windows 版本、显示器布局和每个 DPI。截图、脱敏日志、网络记录及数据前后对比存入 build/regression，结果文件不得包含密码、验证码或 Token。

先运行 `python tests/manual/prepare.py --output build/manual-results.json`，按下面步骤记录结果与证据路径。所有项默认 BLOCKED；完成后填写 PASS 或 FAIL、验收人和时间，再运行 release 套件。源码变化后必须重新验收。

## M-E2E-DESKTOP：完整桌面端到端

前置：Windows 桌面、隔离环境；测试构建和证据对应同一源码指纹。

操作：使用两个独立客户端目录和两个节点；从真实邮件注册到删除好友完整走一遍，中途终止客户端并重启。

预期：图文、草稿、待确认消息和补拉不丢；重置后旧密码失败；删除后发送被拒绝。

数据及清理：只允许测试账号、私有数据库和客户端目录变化；注销两个测试客户端、回收本轮进程/容器；保留脱敏证据。

证据：至少一份截图/脱敏日志，以及涉及数据或网络时的前后对比。
